About Nova AI

Nova AI is a simulated AI made with JavaScript. It does not use a real AI model or API.

It can explain many built-in topics, do basic math, remember information, and help with certain questions, but it has limits.

If Nova doesn't know how to answer something, it will tell you that it can't answer the question instead of pretending it knows.
